# NEET PG 2030 Plan

A study tracker: learn each topic once, then review it at 7, 21, 45, 90, 150 and 300 days. It works out your due dates.

**Live page:** https://syeliqx.github.io/Plan/

## Set up GitHub Pages (one time)

1. Open this repo and tap **Settings**.
2. Tap **Pages** in the left menu.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set **Branch** to **main** and the folder to **/ (root)**, then tap **Save**.
5. Wait 1 to 2 minutes. Reload the Pages settings until it says your site is live.

The repo must contain a file named exactly `index.html` in the top folder. It already does.

## Using it

- Open the live link on any device. On a phone, use the browser menu and choose **Add to Home Screen**.
- Your ticks are saved in the browser on that device. A different phone, browser or private window starts empty.
- Don't clear the browser's site data, or your progress goes with it.

## Updating it

Tap **Add file → Upload files**, upload the new `index.html` with the same name, and commit. It replaces the old one. Your saved progress stays.

## If the link shows a 404 page

- Check that Pages is turned on (steps above) and wait a few minutes.
- Check that the file is called `index.html`, all lowercase, and not inside a folder.
- Check that the link ends with `/Plan/`, with a capital P, as the repo is named `Plan`.
- Reload the page with a hard refresh, or try a private window.
