# NEET PG 2030 Plan

A study tracker: learn each topic once, then review it at 7, 21, 45, 90, 150 and 300 days. It works out your due dates.

**Live page:** https://syeliqx.github.io/neet-pg-2030-plan/

## Put it on GitHub (from your phone or browser)

1. Sign in to GitHub as **syeliqx**.
2. Tap **+ → New repository**. Name it `neet-pg-2030-plan`, set it to **Public**, and tap **Create repository**.
3. On the empty repo, tap **uploading an existing file**.
4. Upload **index.html** and this **README.md**, then tap **Commit changes**.
5. Open **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main** and folder to **/ (root)**, then **Save**.
6. Wait 1 to 2 minutes. Your page is then live at the link above.

## Using it

- Open the live link on any device. On a phone, use the browser menu and choose **Add to Home Screen**.
- Your ticks are saved inside the browser on that device. A different phone, browser or private window starts empty.
- Don't clear the browser's site data, or your progress goes with it.

## Updating it later

On the repo, tap **Add file → Upload files**, upload the new `index.html` with the same name, and commit. It replaces the old one. Your saved progress stays, because it lives in your browser.
